# Gamemikle v12.1

Jogo web estático. A versão 12.1 agrupa os controlos do jogo num menu compacto no lado direito; o joystick continua visível à esquerda.

## Deploy no Netlify
- Branch de produção: `main`
- Diretório de publicação: `.` (raiz)
- Comando de build: vazio

O ficheiro principal é `index.html`. O ficheiro `supabase_v12_setup.sql` contém a configuração adicional do banco para funcionalidades online. Se já executaste esse SQL com sucesso, não precisas executá-lo novamente. Nunca coloques chaves secretas do Supabase no HTML público.
